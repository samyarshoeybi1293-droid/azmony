# آزمونی ۲

سامانه فارسی آزمون چهارگزینه‌ای با Flask و SQLite. نسخه جدید بر اساس نسخه قبلی است و ساختار پایگاه داده آن را حفظ می‌کند.

## اجرای ویندوز
فایل ZIP را استخراج کنید و CMD را در پوشه‌ای باز کنید که app.py در آن قرار دارد.

```
python -m pip install -r requirements.txt
python app.py
```

http://127.0.0.1:5000

نام کاربری محلی اولیه admin و رمز اولیه Azmooni@1405! است؛ فقط برای تست محلی. در داشبورد امکان تغییر رمز وجود دارد. برای حفظ داده‌های نسخه قبلی، پس از توقف برنامه و تهیه نسخه پشتیبان، فایل azmooni.sqlite3 قبلی را کنار app.py جدید قرار دهید.

## انتشار روی Render
تمام محتویات پوشه (شامل render.yaml) را در ریشه یک مخزن Private در GitHub قرار دهید. فایل دیتابیس، اطلاعات دانش‌آموزان و رمزهای محرمانه را منتشر نکنید. در Render از New > Blueprint مخزن را متصل کنید، مقدار ADMIN_PASSWORD را یک رمز جدید، قوی و غیرقابل حدس تعیین کنید و تنظیمات را بررسی کنید. Blueprint برای پلن پولی starter و دیسک پایدار تنظیم شده؛ هزینه را قبل از تأیید بررسی کنید. سرویس رایگان با SQLite محلی برای داده واقعی مناسب نیست. SECRET_KEY به صورت خودکار ساخته می‌شود و COOKIE_SECURE برای HTTPS فعال است. اگر به جای Blueprint از Web Service استفاده می‌کنید، دستور Build همان pip install -r requirements.txt و دستور Start برابر gunicorn --workers 1 --threads 4 --bind 0.0.0.0:$PORT app:app است. متغیرهای محیطی و دیسک را مطابق render.yaml تنظیم کنید. متغیر ADMIN_PASSWORD فقط هنگام ایجاد نخستین حساب مدیر اثر دارد.

## آزمون و امنیت
python test_smoke.py برای بررسی مسیر ورود، ساخت آزمون، ذخیره پاسخ، پایان زمان و گزارش است. پیش از استفاده واقعی، تست مرورگر، تست همزمانی، تهیه نسخه پشتیبان منظم، محدودسازی تلاش ورود و بررسی امنیت لازم است. رتبه‌بندی دانش‌آموز پس از ۱۰ پاسخ‌برگ تکمیل‌شده نمایش داده می‌شود و نام دیگران با شناسه جایگزین شده است؛ مدیر همه اسامی را می‌بیند. نمره‌های برابر رتبه برابر دارند. جدول ۱۰ ردیف اول را نمایش می‌دهد. پاسخ‌های ذخیره‌شده پیش از پایان زمان در تصحیح لحاظ می‌شوند؛ در صورت قطع ارتباط پیش از ذخیره موفق، حفظ پاسخ تضمین نمی‌شود. آزمون منقضی‌شده با مراجعه دوباره یا ارسال خودکار نهایی می‌شود.
